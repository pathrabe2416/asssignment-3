# QuickCare

A simple and responsive hospital appointment booking website built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[https://pathrabe2416.github.io/asssignment-3/](https://pathrabe2416.github.io/asssignment-3/)

## ✨ Features

- Choose a doctor from the available doctors list
- View each doctor's next available slot
- Select an appointment date and time
- Find the soonest available appointment slot
- Enter patient name and phone number
- Confirm hospital appointments
- View upcoming appointments
- Cancel booked appointments
- Prevent booking of already booked or past time slots
- Basic patient information validation
- Appointment count display
- Responsive layout for different screen sizes
- Live clock display

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Google Fonts — Figtree

## 📌 About

QuickCare is a hospital appointment scheduling assignment that allows users to select a doctor, choose an available date and time, enter patient details, and confirm an appointment.

The application also displays upcoming appointments and allows users to cancel existing appointments.
